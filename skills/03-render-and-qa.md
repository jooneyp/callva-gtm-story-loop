# 03. 렌더와 품질 게이트

## 파이프라인 (Joe 서버)
대본 한 장 → 음성 → 자막 타이밍 → Remotion 렌더 → 자동 검사 → 통과본만 게시 대기열.

- **영상**: Remotion (3인 이하 회사 무료 라이선스). 세로 1080x1920, 30fps.
- **음성**: Gemini TTS로 **대화 전체를 한 번에** 생성한다. 줄마다 감정 지시를 붙여 따로 만들어 이어 붙이지 않는다.
  - 이유: 줄별 감정 지시("격앙된 목소리로")는 어설프게 힘준 연기가 됐다. 사람(준영) 청취 판정에서 탈락했고, 대화 전체 1회 생성본이 "제일 현실적"으로 뽑혔다 (Day 0).
- **자막 타이밍**: 생성된 음성을 Whisper로 받아써서 줄마다 맞춘다.
- **화면**: 상단에 상황 요약 고정, 자막은 화면 47~70% 높이, 화자별 색 구분, 화자 바뀔 때 컷(10초당 2회 이상), 하단 15%(앱 UI 영역) 비움.
- **표기**: "실제 사연 재구성 · AI 생성 이미지·음성". 틱톡·유튜브는 실사형 AI 인물에 AI 생성 표기를 요구한다.

## 자동 게이트 (전부 통과해야 게시)
- ffprobe: 해상도·코덱·프레임, 끝까지 디코드 오류 0, 검은 프레임 0
- Whisper 일치도: 전체 0.95 이상, 자막 구간별 0.85 이상, 자막이 말보다 늦게 뜨거나 말 도중 꺼진 구간 0
- vision 검사: 자막 전 구간에서 글자 잘림·깨짐·얼굴 가림·하단 침범·인물 바뀜 없음
- 첫 음성 0.5초 이내

## 사람 게이트
- 목소리 자연스러움은 모델 점수로 판정하지 않는다. Gemini 채점이 과장된 연기에 감정 5점을 줘서 기준으로 못 쓴다 (Day 0). 새 음성 방식은 준영이 듣고 정한다.

## 비용·시간 (Day 0 실측)
- 렌더 한 편 16~22초, 편당 약 6~8원 (TTS). 같은 대사 재렌더는 0원.

## 금지
- 이 서버 GPU에서 영상 생성 모델을 돌리지 않는다. Day 0에 오픈소스 영상 모델을 돌리다 GPU가 떨어져 받아쓰기 서비스가 3시간 멈췄다. 인물 영상 컷은 외부 생성 서비스로 만든다.
