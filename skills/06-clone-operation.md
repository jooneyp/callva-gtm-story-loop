# 06. Clone을 루프에 붙이는 법

## 구조 (m4max의 Clone 앱)
- 프로젝트 '콜바 GTM' → 목표 G-001 '1인 전문직 사무소 셀프가입 루프' (8개 업종으로 확장)
- 목표 폴더 `references.md`: 근거 데이터, 금지사항, 매일 갱신되는 "어제 결과". 개인정보·실제 고객 통화는 넣지 않는다.
- 목표 페이지의 Improving loop 블록: 회차마다 결과가 "Run NN" 섹션으로 쌓인다.

## 실행 방식
- Clone에는 CLI·API가 없다. Joe가 m4max에서 화면 조작 에이전트로 목표 화면의 `Run` 버튼을 눌러 지시문을 보내고, 생성된 파일을 서버로 회수한다.
- Day 0 스모크: 전송부터 결과 파일 생성까지 2분 9초. 훅 5개 점수표와 소재 변형 3세트를 회수했다.

## Clone이 하는 일
- 사연 후보 채점 (`01-story-sourcing.md` 기준)
- 원글 → 재연 대본 추출 (`02-script-extraction.md`, 창작 금지)
- 0초 훅 대사 후보, 마무리 문구 후보
- 지난 회차 지표를 읽고 다음 회차 배분(70/30), 폐기 후보, 커뮤니티 비중 제안

## Clone이 하지 않는 일
- 게시, 광고 집행, 고객 연락. 이건 Joe가 상한 안에서 하고, 상한 밖은 사람이 정한다.
